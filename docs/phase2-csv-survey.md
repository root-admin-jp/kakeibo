# Phase 2 CSV形式調査ドラフト（未コミット・2026-11-07作成）

目的: Kakeibo Phase 2（機関別CSV対応）に入る前に、対象8機関のCSVダウンロード可否を公開情報だけで先に調べたもの。
Phase 1の汎用CSV（`日付,収支種別,金額,大項目,中項目,内容`）は変更なし。ここは調査メモで、実装ではない。
**実ファイルの列名・文字コード・エンコーディングは未確認。** 各機関の実CSVを1件ずつ取り込んでみないとマッピングは確定しない。

## 機関別メモ

### みずほ銀行 — ○
- みずほダイレクトのヘルプ: 「取引明細はPDF形式やCSV形式（パソコンのみ）でダウンロードできます」
- みずほダイレクト通帳の照会可能期間: 申込月の2ヵ月前の1日から照会日の3ヵ月前の月末まで（最大10年間）
- 参考: https://ledgerdrop.tekiba.app/guide/japanese-bank-statement-pdf-layouts-mufg-smbc-mizuho-yucho/ （公式ヘルプの引用まとめ。CSVの列名はここにも非公開と明記）
- 次の作業: 実CSVを1件もらい、列名・日付形式・符号（入出金が別列か符号付き1列か）・文字コードを確認する

### PayPay銀行 — ○
- 公式FAQ: 「Webの取引明細画面からPDF形式、CSV形式でダウンロードが可能です」
- 参考: https://faq.paypay-bank.co.jp/faq/show/1093?site_domain=english
- 次の作業: 実CSVの列を確認する。10年以上前の明細を含む場合はPDFが不可になる旨の注意書きあり（CSV側の制限は要確認）

### 静岡銀行 — ○
- しずぎんWEB-PCバンキングサービスのデジタル通帳: 「CSVファイルやPDFファイルの明細をダウンロードすることができます」「最大10年分のお取引の明細が照会できます（2024年7月1日以降のお取引が対象）」
- 参考: https://www.shizuokabank.co.jp/corporation/efficiency/ebservice/web_pc_banking/pdf/degitalbankbook_20260216.pdf
- 注意: 振込メッセージ等の一部情報は表示されない。WEB-PCバンキング契約が必要
- 次の作業: 実CSVの列を確認する

### イオン銀行 — △未確認
- 見つかったのは法人向け「イオン銀行ビジネスネットサービス」の全銀CSVフォーマット（S-JIS、項目例: 照会口座番号・勘定日・出金金額・入金金額・残高・取引区分・摘要）と、イオンカード明細のCSVダウンロード（暮らしのマネーサイト、過去最大24ヶ月分）で、個人の普通預金明細のCSVとは別物
- 参考: https://www.aeonbank.co.jp/business/pdf/manual_other_01.pdf
- 次の作業: イオン銀行アプリ／インターネットバンキングの入出金明細画面にCSVダウンロードがあるか、本人が画面で確認するのが確実

### SBI証券 — △未確認
- 公開検索ではSBI証券（sbisec.co.jp）の取引履歴・入出金明細のCSVダウンロード手順と列を確認できなかった。SBI VCトレード（暗号資産）のCSV手順とは別物なので混同しないこと
- 次の作業: SBI証券の口座管理画面で「取引履歴」「入出金明細」のCSV保存ボタンの有無と、実ファイルの列を確認する。証券は銀行と違い、売買・入出金・配当・手数料が別ファイルになりやすいので、Kakeiboの取引モデルにどう載せるかは実ファイルを見て決める

### 浜松磐田信用金庫 — △未確認（見込みあり）
- 当金庫固有のCSV手順は公開検索で見つからず
- ただし信金系のインターネットバンキング共通マニュアルには「『CSVファイル』ボタンをクリックすると、ご利用のパソコンに入出金明細をダウンロードすることが可能です」「照会可能期間は過去62日まで」とあり、同系統の仕組みを使っている可能性が高い
- 参考: https://www.shinkin.co.jp/engaru/web-fb/pdf/manual-fb-new/46108_P21P23.pdf （他信金のマニュアルであり、浜松磐田信用金庫のものではない）
- 次の作業: 本人がインターネットバンキングの入出金明細照会画面でCSVボタンの有無を確認する

### モバイルSuica — ×（公式CSVなし）
- モバイルSuica会員メニューサイト: SF利用履歴の表示・印刷はできるが、CSVダウンロードの機能は確認できず
- 制限: 100件以上または26週間経過の履歴は表示できない。前日利用分まで表示
- CSV化の代替: NFCリーダー系アプリ（例: Suica＆PASMOリーダー、ICONIT）が読み取った履歴のCSV出力をうたっているが、Kakeiboへの取り込み経路としては別途検討が必要で、公式経路ではない
- 参考: https://takahashi-hajime.jp/wp-content/uploads/2023/09/3e67ada889738fe753bc549c871d095d-1.pdf
- 影響: Phase 2でSuicaを「CSV取り込み」対象にするのは難しい。手入力＋定期的な履歴の控え、または外部アプリ経由のCSVを汎用CSVに変換する、のどちらかになる見込み

### モバイルWAON — ×（公式CSVの記載なし）
- WAONウェブサイト（PC/モバイル）で利用履歴の確認は可能。ただし「ご利用日から数日遅れて反映される」との注意書きあり
- CSVダウンロードの記載は公開情報で見つからず
- 参考: https://wwws.jp-bank.japanpost.jp/credit1/service/waon01.html （ゆうちょのWAON案内ページ。WAONウェブサイトでの履歴確認の記述あり）
- 影響: Suicaと同様、公式CSV経路は見込み薄。手入力または別経路の検討になる見込み

## Phase 2の進め方（提案）
1. まずCSVあり確定の3行（みずほ・PayPay銀行・静岡銀行）から実ファイルを1件ずつもらって列マッピングを決める
2. 未確認の3つ（イオン銀行・SBI証券・浜松磐田信用金庫）は、本人が各画面でCSVボタンの有無だけ確認する（ログイン操作は本人が行う）
3. Suica・WAONは公式CSVなしが濃厚なので、Phase 2の対象から外すか、手入力補助として扱うかを決める
4. 文字コードは銀行系CSVでShift_JISが多い見込みのため、取り込み側でUTF-8／Shift_JISの自動判定を入れる
